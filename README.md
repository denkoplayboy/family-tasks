# Наш дом 🏡

Семейное приложение для учёта домашних дел. Его используют четверо: глава семьи, мама, дочь и сын. Каждый заходит со своего устройства. Дети отмечают, что сделали, все видят графики и «Битву недели», а у главы семьи есть панель выплат с деталями и кнопкой «Выплачено — обнулить».

- **Без зависимостей:** нужен только Node.js 18+. `npm install` не требуется.
- **PWA:** приложение можно поставить на главный экран телефона, и оно будет выглядеть как обычное.
- **Живые обновления:** когда сын отмечает дело, у сестры и папы сразу появляется уведомление.
- **Светлая и тёмная тема** включаются автоматически по настройке телефона.

## Что умеет

**Дети**
- Отметить дело в пару нажатий: дата (сегодня, вчера или любая за последние 30 дней), количество, часы или сумма чека. Итог считается сразу.
- Подметание и мытьё полов можно отметить **не чаще раза в неделю на всю семью**: кто первый, тот и заработал. Плитка блокируется и показывает, через сколько дней дело снова доступно.
- Главная: сумма к выплате, заработок за неделю, серия дней подряд 🔥, Битва недели с короной 👑 и итогами прошлой недели, общая лента дел.
- Рейтинг: заработок нарастающим итогом, столбцы по неделям, «Кто что делает» и рекорды (лучший день, любимое дело, самая длинная серия).
- История: что ждёт выплаты (ошибочную запись можно удалить), полученные выплаты с деталями.

**Глава семьи**
- Общая сумма к выплате и разбивка по детям.
- По каждому ребёнку: детали всех невыплаченных дел с датами и кнопка **«Выплачено — обнулить»**. Записи не стираются, а уходят в историю выплат. Выплату, сделанную по ошибке, можно отменить кнопкой ↺.
- Можно добавить дело за ребёнка (если тот забыл) или **бонус** на любую сумму.
- Настройки: имена, PIN-коды, **цены** (включая правило «раз в неделю» и отключение дел), скачивание резервной копии.
- **Новые дела:** кнопка «+ Новое дело». Нужно указать название, значок из подобранной сетки, способ оплаты (за раз, за час или процент) и цену. Свои дела можно удалить, при этом история сохраняется.
- **Горящее предложение 🔥:** кнопка с огоньком рядом с ценой. Папа задаёт акционную цену, срок (без срока, сегодня, до конца недели или до даты) и при желании сообщение. Дело появляется у детей на главной с пометкой «Беру!». Первый, кто его выполнит, получает акционную цену, после чего акция гаснет и цена возвращается к обычной. Ограничение «раз в неделю» на акцию не действует.

**Мама (наблюдатель)**
- Видит всё, что видят обе стороны: сумму к выплате и детали по каждому ребёнку, историю выплат, рейтинг, ленту, список дел и цен, активные акции.
- Ничего не может изменить. Зато может ставить реакции 👏❤️🔥😂 на дела детей.

**Для всех**
- Реакции на дела в ленте: ребёнок получает уведомление вроде «Мама: 👏 за „Помыть посуду“».
- Конфетти при отметке дела и при выплате. Для горящих предложений конфетти больше.
- Подсветка главной карточки меняется со временем суток: утром персиковая, днём шалфейная, вечером лавандовая, ночью синеватая.

## Запуск на своём компьютере

```bash
node server.js
```

Затем откройте http://localhost:3000. При первом запуске приложение попросит ввести имена и PIN-коды (4 цифры) для всех четверых.

> Если приложение уже работало с тремя участниками, после обновления мама добавится автоматически. Пока у неё нет PIN, войти она не сможет: глава семьи задаёт его в «Настройках», раздел «Семья».

Переменные окружения (необязательно):

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `PORT` | `3000` | порт |
| `DATA_DIR` | `./data` | где хранятся данные (`db.json`) и ежедневные копии (`backups/`) |
| `APP_TZ` | `Asia/Jerusalem` | часовой пояс семьи: от него зависит, что считается «сегодня» и «эта неделя» (неделя начинается с воскресенья) |

## Как сделать доступным с телефонов

Приложению нужен постоянно работающий сервер с диском, на котором сохраняются данные. Есть три варианта:

### Вариант А: домашний компьютер + Tailscale (бесплатно и приватно)

1. На компьютере, который почти всегда включён (подойдёт и Raspberry Pi), установите Node.js и запустите `node server.js`. Для автозапуска можно использовать `pm2` или systemd.
2. Установите [Tailscale](https://tailscale.com) на этот компьютер и на телефоны всех троих, войдите в один аккаунт.
3. На телефонах откройте `http://<имя-компьютера>:3000`.

Дома без Tailscale работает и адрес в локальной сети: `http://192.168.x.x:3000`.

### Вариант Б: Fly.io (облако, копейки или бесплатно)

```bash
fly launch --no-deploy --copy-config
```

```bash
fly volumes create nash_dom_data --size 1
```

```bash
fly deploy
```

Приложение будет доступно по адресу `https://<имя>.fly.dev`. Данные хранятся на томе `/data`.

### Вариант В: Railway / Render / любой хостинг с Docker

В репозитории есть `Dockerfile`. Важно подключить постоянный диск (volume) к пути `/data`, иначе данные пропадут при перезапуске.

### Установка на телефон

- **iPhone:** Safari → «Поделиться» → «На экран Домой».
- **Android:** Chrome → меню ⋮ → «Добавить на главный экран».

## Если забыли PIN

Глава семьи может поменять любой PIN в настройках. Если забыт PIN самого главы семьи, выполните на сервере:

```bash
node server.js --reset-pin dad 1234
```

(вместо `dad` можно указать `mom`, `daughter` или `son`). Перезапускать сервер не нужно: он сам заметит изменённый файл.

На Fly.io:

```bash
fly ssh console -C "node /app/server.js --reset-pin dad 1234"
```

## Устройство

```
server.js          — HTTP-сервер, API, хранение в JSON, SSE для живых обновлений
public/index.html  — оболочка
public/app.js      — интерфейс (vanilla JS, без сборки)
public/charts.js   — SVG-графики
public/styles.css  — дизайн: мягкие углы, тёплая нейтральная палитра, тёмная тема
public/sw.js       — service worker для PWA
```

PIN-коды хранятся в виде хэша (scrypt). Вход живёт 180 дней. После пяти неверных попыток вход временно блокируется.
